# Contributing to Claude Folder Upload Helper

First of all, thank you for considering contributing to this project! Here's how you can help.

## Development Setup

1. Clone the repository
   ```
   git clone https://github.com/whyismynamerudy/claude-folder-upload-helper.git
   ```

2. Load the extension in Chrome:
   - Open Chrome and navigate to `chrome://extensions/`
   - Enable "Developer mode" (toggle in the top right)
   - Click "Load unpacked" and select the `extension` folder from the cloned repository

3. Make your changes and test them by reloading the extension

## Pull Request Process

1. Fork the repository
2. Create your feature branch (`git checkout -b feature/amazing-feature`)
3. Commit your changes (`git commit -m 'Add some amazing feature'`)
4. Push to the branch (`git push origin feature/amazing-feature`)
5. Open a Pull Request

## Coding Standards

- Follow the existing code style
- Ensure all functions and variables have meaningful names
- Add comments for complex logic
- Test your changes thoroughly

## Reporting Bugs

If you find a bug, please create an issue with:
- A clear title and description
- Steps to reproduce the bug
- Expected behavior
- Screenshots (if applicable)
- Browser version and OS

## Feature Requests

Feature requests are welcome! Please provide:
- A clear description of the feature
- Why it would be useful to the project
- Any implementation ideas you might have

## Questions?

Feel free to open an issue with any questions about the project or the contribution process.
